# Console variables

<!-- Status: checked against 0f6bdf3 -->

Version 1.0 has no console variables. Every setting is a property on the world, the block set, a component or the
project settings; see [Settings](../features/settings.md).

The commandlet for rebuilding content is described in [Editor tools](../features/editor-tools.md).
