# FAQ

**Can it make infinite worlds?** Yes: unbounded worlds are endless in X and Y and streamed around the players; see
[Unbounded worlds](features/streaming.md). Distance detail levels (LOD) aren't in version 1 (see the
[Roadmap](roadmap.md)).

**Does water flow?** Yes, with the optional Fluids module (turn on Enable Fluids in Project Settings > Plugins >
SuperVoxel): Block mode for classic endless sources, Dynamic
mode for water that keeps its volume. Without it, fluid blocks stay put. See [Fluids](features/fluids.md).

**Does it support multiplayer?** Yes. The server applies edits and sends them to clients in batches. Players who join
late get the seed plus the edit journal. See [Multiplayer](features/multiplayer.md).

**Do I have to use every feature?** No. Every feature can be turned off.

**Do I need C++?** No. Generation, editing, saving and pathfinding all work from Blueprint. The full C++ source is
included.

**Can I add my own blocks and textures?** Yes. See [Block set](features/block-set.md) and
[Materials](features/materials.md).

**Can a world be only smooth, or only blocks?** Yes. Each block type is smooth, blocky or fluid, so a world can use
just one kind.

**Does pathfinding replace the navmesh?** For agents walking on the voxel world, yes. It reads the grid directly and
follows edits. You can still use the navmesh elsewhere.

**Does it work with Lumen and Nanite?** It works with Lumen, and ambient occlusion is baked into the mesh. Voxel meshes
that change at runtime don't use Nanite.

**No terrain preview in the editor?** The preview is started when you place or change the world, but it's finished
from the world's tick, and the editor only ticks a viewport while it's **Realtime** (Ctrl+R, or the viewport's
options menu). Unreal turns Realtime off while the editor is in the background (Editor Preferences > General >
Performance > **Use Less CPU when in Background**), so switch it back on, or untick that preference. Also check
**Preview In Editor** on the world is on.

**Which platforms?** Windows (Win64) is built and tested. The code is platform-neutral, but Linux and Mac aren't
verified yet (see the [Roadmap](roadmap.md)).

**Is any of it AI-generated?** No AI-generated assets: all of SuperVoxel's assets (textures, materials and meshes) are generated by code. Claude Code was used to assist with the programming, optimization and bug testing.
