# Support and updates

## Where to ask
- **Email:** [ocozdemir@gmail.com](mailto:ocozdemir@gmail.com)

An issue tracker is announced with the Fab release.

Support never depends on a chat server: the issue tracker and email always work.

## Our promise
- **We answer every report.** The reply time is published with the release.
- **Docs bugs count as bugs.** If something isn't documented, tell us and we'll fix the guide.
- **Engine updates:** every new Unreal 5.x release gets a tested build. Builds for older 5.x
  versions stay downloadable.
- **No breaking changes inside a major version.** Saves, block names and assets stay compatible across 1.x. Any
  change that needs a migration comes with a step in the [changelog](changelog.md).
- **Hitches are bugs.** Edits mesh and cook collision off the game thread; if you see a hitch, report it.

Seller: Onur C Ozdemir.

## What to include
- the engine version and the plugin version;
- the steps to reproduce, and a small map that shows it if you can;
- the `LogSuperVoxel` lines from your log (Window > Output Log).
